## 可复验的玩法

| 标题页路径 | 实际可观察的结果 |
|---|---|
| 开始着陆 | 手工收集 10 铁矿与 5 铜矿可做出 10 磁线圈并完成 1,200 哈希的电磁学研究。 |
| 双矿分流与筛选 | 同一主带上的铁矿走西口、铜矿走东口。堵住筛选口时可以观察另一种货物继续通过。[实机画面](./splitter.png) |
| 集装与流速监测 | 三级带每分钟分别交付 360、720、1,800 件。教学线上同一股水每分钟经过 720 个单件垛、360 个双层垛、180 个四层垛。可从星图远程勾选出口待办。[集装](./piling.png) · [信标](./beacon.png) |
| 仓储与机甲配送 | 机甲领到 32 铁块，配送机回收 48 石料。调低背包上限后配送机继续回收多出的铁块。[配送站](./distribution.png) |
| 喷涂与冶炼对照 | 两条线各投 120 铁矿。增产侧交付 150 铁块，加速侧交付 120 铁块。[双线实测](./coating.png) |
| 黑雾地面防守 | 守住矿区，分析基站回收残骸。拆开地面核心后可在钻孔上建地热站。[地面防守](./ground-defense.png) |
| 行星护盾与中继 | 八台发生器合计输入 192 MW 时全星覆盖，中继原货返航，公共池抵挡一波 900 点轨道伤害。断电使覆盖消退，落地的中继用 6,000 物质建立基地。[实机画面](./planetary-shield.png) · [护盾原图](https://media.dsp-wiki.com/5/54/8_shield_generator_Planet.png) · [中继](https://dsp-wiki.com/Relay_Station) |
| 矿物利用与连续研究 | 同一座八矿点矿机在第六级每分钟开采 384 件，第七级提升至 408 件。[实机画面](./veins-research.png) · [等级依据](https://dsp-wiki.com/Veins_Utilization_(Upgrade)) |
| 异星地质勘查 | 火山灰海岸抽取硫酸供钛合金，曲速飞往水世界后露出石笋，可用石笋制成碳纳米管。[酸海](./acid-coast.png) · [海底矿线](./seabed.png) |
| 黑雾样本与透镜 | 从样本仓取走 1,012 枚黑雾矩阵，机甲用 1,000 枚研究透镜，余下 12 枚与引力透镜合成黑雾透镜。[科技原型数据](https://dsp-wiki.com/index.php?title=Module%3AGameData%2Fprotosets.json&action=raw) · [透镜倍率](https://dsp-wiki.com/Dark_Fog_Lens) |
| 蓝图与建设机 | 框选两台设施和一条分拣器，旋转或放下预建后查看建设机逐件取货、落成。[实机画面](./blueprint.png) |
| 原油精炼与分馏 | 炼油副产的氢一支供能量矩阵，一支循环分馏。接通 300 秒模拟得到 11 重氢和 49 红矩阵。[实机画面](./refinery.png) |
| 跨星球物流线 | 两艘各装 200 钛石的运输船从熔岩星返回，随后运输机在初始行星分拨。[实机画面](./logistics.png) |
| 跨星球输电 | 熔岩行星地热驱动充电，物流塔实际输送满电池和空壳。接收地放电供给电网。[实机画面](./power-exchange.png) |
| 巨星轨道采集 | 在赤道添加第四座采集器，查看毛产、自耗、净产，等待运输船从云顶取货。[实机画面](./orbital-collectors.png) |
| 海岸整地与填海 | 默认种子 747183。取土耗 9 地基、得 5,771 沙土。填海再耗 9 地基与 2,196 沙土，可在新陆地上建仓；换色免费。[实机画面](./coast.png) |
| 恒星工程沙盒 | 观察火箭补齐框架、帆融入壳面和三种发电贡献。到另一颗恒星可以独立规划戴森球。[恒星工程](./stellar-yard.png) · [星团与航线](./cluster.png) |
| 宇宙矩阵与主线交付 | 教学预置前 3,996 份研究。把射线接收站切到光子模式，经过粒子对撞和实验室补齐末批白矩阵并完成交付。[交付记录](./mission.png) |
